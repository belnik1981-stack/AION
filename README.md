# AION

AION — исследовательский испытательный образец многомодельной AI‑системы.
Он получает отдельные ответы моделей, сопоставляет утверждения и расхождения,
ротирует роли Planner / Analyst / Critic / Synthesizer / Verifier, сохраняет
неопределённость и не считает согласие моделей доказательством истины.

Статус: **готов к воспроизводимой офлайн‑приёмке; не является production‑сервисом**.
Актуальный реальный двухмодельный запуск должен отдельно выполнить владелец со
своим ключом OpenRouter и доступными в этот момент бесплатными моделями.

## Одна команда приёмки

Требуются Git, Bash и Python 3.10+:

```bash
git clone --branch master https://github.com/belnik1981-stack/AION.git
cd AION
bash scripts/owner_acceptance_test.sh
```

По умолчанию launcher:

- требует чистый checkout, точное совпадение с текущим `origin/master` и
  правильный remote;
- создаёт отдельную локальную копию точного commit, поэтому тест не записывает
  данные в основную память AION;
- запускает компиляцию, offline harness, интеграционные и adversarial trials;
- повторно проверяет неизменность Truth и основной runtime‑памяти;
- сохраняет закрытые текстовый и JSON‑отчёты в `test-reports/`.

Ожидаемый итог: `[ACCEPTANCE PASS]`. Такой PASS подтверждает выполненные тесты,
но не объективную истинность модельных ответов.

## Ограниченный live‑тест двух моделей

Live‑режим является отдельным явным действием и принудительно использует
free‑only политику:

```bash
read -r -s -p "OpenRouter API key: " AION_API_KEY; echo
export AION_API_KEY
bash scripts/owner_acceptance_test.sh --live
unset AION_API_KEY
```

Можно заранее указать ровно два доступных ID разных авторов:

```bash
export AION_MODELS='ПЕРВАЯ_МОДЕЛЬ:free,ВТОРАЯ_МОДЕЛЬ:free'
```

Ключ не записывается в Git и не печатается launcher. Бесплатность зависит от
актуальных условий провайдера. Общий или неустановленный HTTP 429 останавливает
все дальнейшие запросы. В автоматическом выборе подтверждённый лимит только
конкретного upstream-провайдера позволяет перейти к другому бесплатному ID,
не повторяя отказавшую модель; явно заданная пара не подменяется.

## Локальный интерфейс

Для личной проверки этапа 1 с ярлыка Termux:Widget и вопросом в браузере
используйте [инструкцию этапа 1](docs/checkpoints/PROJECT_CHECKPOINT_2026-10-26_STAGE_1.md).

После приёмки сервер запускается только на `127.0.0.1:8080`:

```bash
read -r -s -p "OpenRouter API key: " AION_API_KEY; echo
export AION_API_KEY
bash start_app.sh
```

Не публикуйте порт напрямую в интернет: встроенной пользовательской
аутентификации нет. Для удалённого хоста используйте защищённый SSH‑туннель.
