## Личная проверка с виджета Termux и вопросом в браузере

Для этого испытания нужны приложения **Termux** и **Termux:Widget** на одном
Android-устройстве. Установите их из одного источника, затем откройте Termux.
Значок виджета появится позднее на главном экране Android. Ключ OpenRouter
вводится скрыто при запуске и нигде не сохраняется. До нажатия кнопки вопроса
в браузере скрипт не обращается к модели.

### 1. Один раз подготовьте проект в Termux

Вводите команды по одной строке, после каждой нажимайте Enter:

```bash
pkg update -y
pkg install -y git python python-ensurepip-wheels clang make
git clone --branch codex/stage-1-persistent-memory-20261026 https://github.com/belnik1981-stack/AION.git ~/AION-stage1
cd ~/AION-stage1
python3 -m pip install -r requirements-core.txt
bash scripts/install_termux_widget.sh
```

`~/AION-stage1` — новая папка с копией PR в домашнем каталоге Termux.
Команда `cd ~/AION-stage1` открывает эту папку. Если вы уже создали её по
ранней инструкции, не повторяйте `git clone`: начните с `cd ~/AION-stage1`,
затем выполните `git pull --ff-only` и последние две команды выше.

### 2. Добавьте виджет на главный экран телефона

Вернитесь на главный экран Android. Удерживайте палец на пустом месте,
откройте «Виджеты», найдите **Termux:Widget** и перетащите его на экран.
Если список ярлыков не обновился, нажмите значок обновления на виджете.
Виджет должен показать ярлык `AION_stage1`.

### 3. Отправьте один вопрос

Нажмите `AION_stage1`. Откроется окно Termux с приглашением
`Ключ OpenRouter (ввод скрыт):`. Вставьте собственный ключ и нажмите Enter.
Символы ключа не будут видны; это нормально. Скрипт запускает AION с
`AION_FREE_ONLY=1`, одной моделью `openrouter/free`, и открывает браузер по
адресу `http://localhost:8080`. На странице должно быть `AION Control Panel`.

В верхнем блоке **CONTROL — single model / single cycle** введите:

```text
Ответь одним предложением: сколько будет 2 + 2?
```

Нажмите **«Запустить контрольный цикл»** один раз и дождитесь обновления
страницы. В блоке **CURRENT STATE / LAST RESPONSE** должны появиться ваша
задача как `last_user_prompt`, непустой `last_answer` и `status: idle`.
В блоке **OPERATIONAL MEMORY** найдите эту же задачу со статусом `completed`.
Это реальный запрос выбранной бесплатной модели через ваш ключ. HTTP 401,
429, пустой ответ или `error` означают, что личный тест не прошёл; при 429
не отправляйте сразу повторный вопрос.

### 4. Перезапустите AION и проверьте память

Переключитесь из браузера обратно в окно Termux с работающим сервером.
Остановите его сочетанием **Ctrl+C** (в Termux клавиша Ctrl доступна через
дополнительный ряд клавиш или сочетание «громкость вниз + C»). Дождитесь
сообщения `[AION] Локальный сервер остановлен.`

Снова нажмите `AION_stage1` на главном экране. Повторно введите ключ: он
специально не хранится. Когда браузер откроется, **не отправляйте новый
вопрос**. Откройте блоки состояния и памяти. Те же `last_user_prompt`,
`last_answer`, запись задачи и её `task_id` должны остаться на месте.
Если они сохранились без подмены, личная проверка постоянной памяти прошла.

Испытание с виджета подтверждает сохранение завершённого ответа после
перезапуска. Автоматический тест `test_session_persistence.py` отдельно
проверяет восстановление прерванной задачи. Проверка не доказывает работу
двух разных моделей или истинность их выводов — это следующие этапы.
