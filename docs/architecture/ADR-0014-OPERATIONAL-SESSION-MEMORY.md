# ADR-0014: постоянная операционная память сеанса

Статус: реализовано в отдельном PR; ожидает личной проверки владельца.

## Решение

Существующие атомарные JSON/JSONL хранилища принятых данных сохраняются.
Отдельная SQLite-база хранит историю запусков, ошибки, незавершённые задачи,
решения владельца, несекретный профиль и контрольные точки. SQLite входит в
стандартную библиотеку Python для Linux/Termux. Транзакции с WAL и
`synchronous=FULL` фиксируют каждый этап до следующего действия.

Задача записывается до вызова провайдера. Результат фиксируется после обработки.
Аварийно оставшаяся задача показывается как `interrupted`; AION не повторяет
API-запрос автоматически. Ответы и ошибки в этой базе являются журналом
наблюдений, не trusted memory и не Truth.

Профиль допускает только перечисленные в `memory/session.py` параметры моделей
и бюджета; переменные окружения имеют приоритет. Ключи и токены исключены из
профиля, тексты проходят ограниченное redaction до записи. Файлы размещены в
закрытом каталоге и исключены из Git.

Контрольная точка создаёт проверенную резервную SQLite-копию. При повреждении
чтение и запись прекращаются. Явное восстановление сохраняет прежнюю базу и
её WAL/SHM файлы для разбора; резервная копия может быть старше последних
записей. Перед восстановлением все процессы AION нужно остановить.
Автоматической подмены базы нет.

## Границы

Pattern redaction не распознаёт все возможные секреты. SQLite-файлы не
зашифрованы. Транзакция журнала и уже существующая запись episodic memory
не являются единой межфайловой транзакцией; при сбое между ними задача
остаётся видимой как прерванная или с ошибкой, а данные не очищаются молча.
