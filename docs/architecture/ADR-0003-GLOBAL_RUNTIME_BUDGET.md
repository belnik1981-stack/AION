# ADR-0003: общий runtime-бюджет

Статус: принято и проверено offline
Дата: 2026-10-19

## Контекст

`max_iterations` ограничивал число раундов, но один раунд выполняет несколько
LLM-ролей, а усечённый ответ допускает один повтор. Поэтому лимит раундов не был
верхней границей числа сетевых запросов. Timeout провайдера также применялся к
каждому запросу отдельно, а успешное HTTP-тело читалось без ограничения размера.

## Решение

- каждый `run_pipeline` получает один монотонный deadline из read-only
  `execution.timeout_seconds` в Truth;
- все обращения через `core.llm.ask_llm`, включая повтор после усечения,
  расходуют общий счётчик;
- `AION_MAX_LLM_CALLS` по умолчанию равен 24 и допускается только в диапазоне
  `1..32`;
- в одном запуске разрешено не более четырёх явно названных моделей;
- timeout каждого HTTP-запроса не может превышать оставшееся время общего
  deadline;
- `AION_MAX_RESPONSE_BYTES` по умолчанию равен 1 MiB и ограничен диапазоном
  `1 KiB..4 MiB`; превышение блокируется до JSON-разбора;
- исчерпание deadline/числа вызовов и превышение размера ответа возвращают
  стабильные категории без текста недоверенного исключения;
- снимок `runtime_budget` добавляется в результат pipeline.

Некорректная конфигурация отклоняется до сетевого вызова. Повтор усечённого
ответа не получает отдельной квоты и расходует тот же общий бюджет.

## Проверка

`tests/harness/test_runtime_budget.py` воспроизводимо проверяет deadline,
суммарный счётчик, ограничение числа моделей, ошибочную конфигурацию и запрет
одномодельного успеха при остановленном втором запросе.

`tests/harness/test_provider_resilience.py` проверяет ограничение HTTP-тела,
привязку provider timeout к оставшемуся deadline и отсутствие утечки текста
неожиданного исключения.

Оба теста входят в `scripts/full_life_test.sh` и обязательные PR workflows.

## Границы решения

- urllib использует оставшееся время как socket timeout; это не обещание
  мгновенной принудительной отмены уже выполняющегося системного вызова;
- бюджет действует на основной pipeline через `core.llm`; необязательный
  Agents SDK runtime остаётся отдельным, пока не будет явно интегрирован;
- ограничение ресурсов не подтверждает истинность модельного ответа и не
  меняет `truth_verified=False` для LLM-рецензии.
