# Две версии AION через Termux:Widget

До слияния PR можно сравнивать исходный MASTER и локальный результат применения
PR на одном адресе `http://127.0.0.1:8080`. На GitHub ничего не сливается.

## Установка

Нужны Termux и Termux:Widget из совместимого источника (например, обе программы
из F-Droid), Git, Bash, Python 3.10+ и доступ к GitHub/PyPI. Termux:API не требуется.
Запускайте установку в обычном терминале Termux, а не внутри другой программы.

После отправки ветки PR на GitHub установка и обе проверки выполняются одной
командой (временный bootstrap-клон удаляется, рабочие версии сохраняются):

```bash
(set -e; command -v git >/dev/null || pkg install -y git; aion_widget_bootstrap=$(mktemp -d); trap 'rm -rf -- "$aion_widget_bootstrap"' EXIT; git clone --depth 1 --branch feat/termux-widget-dual-launch https://github.com/belnik1981-stack/AION.git "$aion_widget_bootstrap/AION"; bash "$aion_widget_bootstrap/AION/scripts/install_termux_widget.sh" --pr auto --verify --verify-live)
```

Bootstrap устанавливает только отсутствующие инструменты. На Android для
сборки закреплённого PyYAML могут потребоваться Clang, Make и libyaml; их наличие
проверяется автоматически. Существующий Python и окружение основного AION не
обновляются командой установки ради обновления версии.

Из клона ветки PR:

```bash
bash scripts/install_termux_widget.sh --pr auto --verify --verify-live
```

Установщик использует экспортированные `AION_*` и ранее сохранённую конфигурацию.
Ключ не печатается и не попадает в ярлыки/Git. Поскольку Widget не наследует
переменные другого терминала, конфигурация сохраняется в
`~/.config/aion-widget/runtime.json` с правами `600`. Если ключ отсутствует,
установщик запрашивает существующий ключ скрытым вводом. Для явно выбранного
dotenv-файла поддерживается `--config-file /полный/путь/.env`; файл читается как
данные, без исполнения команд и подстановок shell. Файлы с ключами автоматически
не разыскиваются. Для проверки только интерфейса есть `--offline`.

Создаются:

- `~/AION`: если каталог существует, его файлы, история и ветка сохраняются.
  Он должен быть на ветке `master` с origin данного репозитория. Незакоммиченные
  изменения допускаются и обозначаются как `local changes` в интерфейсе.
  Отстающий MASTER не обновляется автоматически: установщик сообщает об отличии.
- `~/AION-PR-test`: независимый клон свежего `master` с `git merge --no-commit
  --no-ff` PR head. HEAD остаётся на базовом master; изменения PR находятся в
  индексе/рабочем дереве. Идентификаторы base, PR head и merge tree записаны в
  `.git/aion-widget-preview.json`. Это ожидаемое незакоммиченное состояние.
- `~/.local/share/aion-widget`: controller, два отдельных Python venv, приватные
  журналы и сведения запущенного процесса. Память/состояние MASTER и TEST PR
  находятся в соответствующих каталогах и не копируются друг в друга.
- `~/.shortcuts/AION MASTER` и `~/.shortcuts/AION TEST PR`: исполняемые команды.

Если существующий TEST PR отличается от нового preview, установка отказывается
его перезаписывать. Остановите его через controller, сохраните каталог под другим
именем и повторите установку. Обновление не удаляет пользовательские файлы.

`--pr auto` находит PR по совпадению head ветки `feat/termux-widget-dual-launch`
с GitHub pull ref. Можно указать номер явно: `--pr 123`. Нужен уже опубликованный
PR; наличие одного локального клона/ветки не заменяет отправку на GitHub.

Установка и `--verify` не останавливают работающий сервер и не занимают порт 8080.
Проверка запускает офлайн-тесты в тестовой копии; пути отчётов выводятся в конце.
Интерактивные проверки обеих версий выполняются уже командами виджета.

`--verify-live` отдельно разрешает реальное ограниченное испытание двух
бесплатных моделей в изолированной временной копии TEST PR. При успехе, если
пара ещё не задана пользователем, два проверенных ID сохраняются для обоих
ярлыков. Существующая пара не подменяется. При ошибке провайдера установка
остаётся на месте, работающий сервер не останавливается, команда возвращает
ненулевой статус и путь отчёта. Для установки без генерации опустите этот флаг.

## Виджет и переключение

Добавьте на рабочий стол виджет **Termux:Widget**: он покажет **AION MASTER**
и **AION TEST PR**. Если старый виджет уже установлен, обновите его список
кнопкой обновления. Если это закреплённый старый одиночный ярлык, вручную
замените его новым виджетом Termux:Widget через меню рабочего стола Android.
Скрипт не управляет домашним экраном Android.

Распознаваемые старые AION-ярлыки (`AION`, `aion`, `AION.sh`, `aion.sh`,
`start_aion.sh`, содержащие запуск `AION`/`server.py` или `start_app.sh`)
перемещаются в `~/.local/share/aion-widget/shortcut-backups/`. Другие ярлыки
остаются без изменений. Неизвестные старые имена не удаляются автоматически.

Каждая команда проверяет новую версию до остановки предыдущей, останавливает
управляемый AION через локальную команду с приватным токеном, запускает выбранную
версию и открывает браузер через `termux-open-url`. В заголовке страницы/вкладки
видны **MASTER** или **TEST PR**, commit и для теста PR/merge tree. Кеширование
страницы отключено. Открыт только loopback, внешняя публикация порта не нужна.

Старый `python server.py` останавливается только после проверки точного пути,
владельца и его слушающего сокета, через pidfd, исключающий повторное использование
PID. Если Android закрывает `/proc` или не поддерживает pidfd, launcher не посылает
сигнал: один раз нажмите Ctrl+C в терминале старого AION и повторите запуск.
Неизвестный владелец порта вызывает отказ. `pkill`/`killall` не используются.

Дополнительные команды:

```bash
python ~/.local/share/aion-widget/launcher.py status
python ~/.local/share/aion-widget/launcher.py stop
```

Установка сохраняет конфигурацию провайдера, но команды сравнения допускают
только OpenRouter и бесплатные ID (`openrouter/free` или `:free`). Другие настройки
не перезаписываются: запуск отказывает до остановки действующего экземпляра.
Два разных ID/автора не доказывают независимость обучения или истинность ответов.

## Проверки

Автоматический тест без Android:

```bash
PYTHONPATH=. python tests/harness/test_termux_widget.py
```

Он создаёт локальный Git remote с PR ref и проверяет сохранность грязного MASTER,
merge preview без merge commit, права файлов, вызов браузера, реальные HTTP-запуски
и MASTER → TEST PR → MASTER, отказ при постороннем процессе и платной модели,
идемпотентность установки и проверку старого процесса. Android-браузер, поведение
лаунчера домашнего экрана и ограничения конкретной версии Android проверяются
на телефоне отдельно.

Реальное испытание двух моделей — отдельная free-only команда с сохранённым
ключом, выполняемая в временной копии исходников без записи в обе рабочие версии:

```bash
python ~/.local/share/aion-widget/launcher.py live-test master
python ~/.local/share/aion-widget/launcher.py live-test test
```

Controller использует сохранённый ключ сам; экспортировать его из приватного
файла через вывод на экран не нужно.
Офлайн PASS не подтверждает ответ реального провайдера.
