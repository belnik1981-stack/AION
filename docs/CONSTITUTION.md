# AION Constitution

## Основные принципы

1. Любое изменение должно иметь цель.
2. Перед изменением проводится проверка.
3. После изменения выполняется проверка результата.
4. Архитектура документируется.
5. Простота предпочтительнее сложности.
6. Минимум зависимостей.
7. Код должен быть понятен человеку.
8. Любая новая функция должна быть расширяемой.

Версия: 0.1
